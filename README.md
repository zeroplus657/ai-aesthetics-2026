# AI时代的审美与网页设计

面向北京大学与清华大学学生科幻协会同学的个人实践分享。

三部分：个人AI投入、两个前端风格案例、面向读者与情景的审美理解。米白、铁锈红、芥末黄、深绿与原创几何纪念碑插画，结合mid-century modern和苏联时代建筑/航天美术的构图感。

- 费用及token数字由分享者提供，并非官方定价或经过平台审计的统计。
- 两个实例直接内嵌原站。文献库仍使用原站访问验证，本站不保存、传递或公开登录状态。
- 默认被动预览，点“操作网页”才启用框内交互，避免手机滑动被内嵌页面截获。
- 原生HTML、CSS、JavaScript，无构建工具，无后端，不收集个人资料。
- 原创SVG只作构图装饰，不使用校徽、协会标志或原版游戏素材。
- 演讲版仅保留主要信息：米白天空贯穿全页，辅助讲解交由现场口述；费用仍为个人支出，人民币为粗略折算。
- Codex小机器人为全站固定吉祥物；Tibo头像由分享者提供，用内置图像编辑精修为透明头部素材，没有脖子、衣领、圆框或底色，原图保留。
- 用量上方使用桌面应用图标；品牌资产用于指代相应产品，不表示官方合作或背书。
- 末页为“祖国母亲在召唤”的原创低多边形意象建模，不是扫描或测绘复刻；以几何衣褶、举剑与伸臂表达雕塑姿态。建模由本地JavaScript定义三维顶点、切面与光照，无第三方模型依赖。
- 雕塑相对第三版放大1.5倍，增加衣褶、发丝、面部与剑身细节及程序生成的石材颗粒；手与剑缓慢小幅上下摆动。头像环绕和雕塑均支持手动暂停、系统减少动态；离开相应区域或页面后台时停止运行。
- 可直接打开index.html或通过HTTP访问；不需要本地构建。
